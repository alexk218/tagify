# Tagify: music tagging and playlist organization for Spotify

Tag, rate and organize your Spotify library your own way: custom tags, energy levels, star ratings, and smart playlists built from them, right inside the Spotify desktop app. Tagify is a free, open source [Spicetify](https://github.com/spicetify/cli) custom app.

## Install Tagify

You'll need the **Spotify desktop app**, opened and signed in at least once.

- **macOS:** download `TagifyInstaller-mac.dmg` from the [latest Tagify installer release](https://github.com/alexk218/tagify-installer/releases)
- **Windows:** download `TagifyInstaller.exe` from the [latest Tagify installer release](https://github.com/alexk218/tagify-installer/releases)

Open the installer and click **Install Tagify**. It sets up Spicetify and Tagify for you. Then open Spotify and choose **Tagify**. Use the installer again whenever you want to update or repair your setup.

<details>
<summary>Linux installation</summary>

Install [Spicetify](SPICETIFY_INSTALLATION.md) first, then run:

```bash
curl -fsSL "https://raw.githubusercontent.com/alexk218/tagify/main/install.sh" | bash
```

Restart Spotify and choose **Tagify**.

</details>

## FAQ

**Is Tagify free?** Yes. The Spotify desktop app and the website are both free, and this app is open source.

**Does it work with Apple Music?** The desktop app is for Spotify. On [tagify.fm](https://tagify.fm) you can tag Apple Music songs too.
