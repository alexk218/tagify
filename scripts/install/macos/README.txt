TAGIFY FOR MAC

1. Open Tagify Installer.app. You can run it directly or drag it into Applications.
   A short tutorial welcomes you. Reopen it at any time with Tutorial.
2. Download the Spotify Mac desktop app from https://www.spotify.com/download/mac/.
   Tagify works inside the desktop app; the web player and mobile apps cannot
   be used for setup. Have Spotify installed and signed in. Spotify setup help walks
   you through this. Leave a new Spotify installation open for at least a minute.
3. Choose Install Tagify. Setup verifies the latest stable Tagify and Spicetify
   downloads, saves a copy of your current setup, and briefly closes Spotify.
4. Choose Open Spotify and choose Tagify in Spotify.

When Tagify is already working, Open Spotify launches it without reinstalling.
Choose Tagify missing? Repair if it disappears. A newer Tagify release changes
the main button to Update Tagify; a Spicetify update offers Update setup.
Check setup refreshes the status and updates.
Your saved tags, ratings, themes, and other apps stay in place. The installer
preserves Marketplace if you already have it, without adding it automatically.

Block Spotify updates is checked by default to help keep Tagify working. Your
saved tags stay safe. Uncheck it to allow automatic Spotify updates again, then
choose Apply Changes. The installer shows the actual setting and any unsaved
choice. Changing this setting briefly closes Spotify without reinstalling Tagify.

The installer checks for newer Mac installer releases when you open it. An update
shows What's new, Update now, and Later. Later keeps a reminder in the window.
Update now downloads and verifies the new installer into Downloads. Choose Show
download, then open it to finish updating. Older prototypes need one manual
upgrade to gain these notifications. Checks happen while the installer is open.

If your Spotify copy needs permission to allow changes, macOS asks for your
administrator password. The rest of setup runs using your own Mac account.

If setup fails, read the message and choose Try again. View details and Copy
diagnostics help with troubleshooting. Open Log and Show Backup are available
in the details window. Do not delete your Spotify user data.

The .pkg alternative places Tagify Installer in Applications and opens it.
If it doesn't open automatically, open Tagify Installer from Applications.

Requires macOS 12 or later, an Intel or Apple Silicon Mac, the Spotify desktop
app, and an internet connection. No Terminal, Homebrew, or Xcode is needed.
